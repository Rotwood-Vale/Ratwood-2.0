# Class-selection fonts

Unmodified TrueType fonts from the official Google Fonts repository:

- VT323 Regular: `vt323-regular.ttf` (VT323-OFL.txt).
- Jacquarda Bastarda 9 Regular: `jacquarda-bastarda-9-regular.ttf` (Jacquarda-Bastarda-9-OFL.txt).
- Silkscreen Regular and Bold: `silkscreen-regular.ttf` and `silkscreen-bold.ttf` (Silkscreen-OFL.txt).

Source revision: https://github.com/google/fonts/tree/7af0d90b4d532ffa4b041937b560c6df4e7b1e95/ofl
