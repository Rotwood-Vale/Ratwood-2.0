# KCD-Style Alchemy System

This document explains the new Kingdom Come: Deliverance (KCD) style alchemy system added to Ratwood.

## Overview

The KCD-style alchemy system allows you to create various herbal preparations by boiling a single herb with different base reagents in a cauldron. The resulting products can be boiled again to create more concentrated forms.

**NEW:** The cauldron can now process multiple base reagents simultaneously! If you add water, oil, and wine to the cauldron with a single herb, it will create all three products at once.

## How It Works

1. Fill a cauldron with at least 30 units (10 oz) of one or more base reagents
2. Add exactly ONE herb to the cauldron
3. Light the cauldron and wait for it to finish brewing
4. The cauldron will produce reagents named after the herb (e.g., "rosa tonic" or "mentha oil")
5. Each 30 units of base reagent produces 10 units of the final product

## Base Reagents and Products

### NOVICE Level (Skill 0-1)

| Base Reagent | + Herb | = Product | Ratio |
|--------------|--------|-----------|-------|
| Water (30u+) | Any Herb | **Herb Tonic** - Mild healing effect | 30u → 10u |
| Cooking Oil (30u+) | Any Herb | **Oil of Herb** - Mild stamina restoration | 30u → 10u |
| Wine (30u+) | Any Herb | **Herb Elixir** - Mild energy restoration | 30u → 10u |

### AMATEUR Level (Skill 2)

| Base Reagent | + Herb | = Product | Ratio |
|--------------|--------|-----------|-------|
| Any Spirits* (30u+) | Any Herb | **Herb Bitters** - Moderate healing | 30u → 10u |
| Acid (30u+) | Any Herb | **Vitriol of Herb** - Potent but risky healing | 30u → 10u |
| Herb Tonic (30u+) | Same Herb | **Herb Concentrate** - Stronger healing than tonic | 30u → 10u |

*Spirits = any alcoholic beverage except wine (beer, rum, aqua vitae, vodka, etc.)

### JOURNEYMAN Level (Skill 3)

| Base Reagent | + Herb | = Product | Ratio |
|--------------|--------|-----------|-------|
| Oil of Herb (30u+) | Same Herb | **Herb Paste** - Strong stamina restoration | 30u → 10u |
| Herb Elixir (30u+) | Same Herb | **Herb Syrup** - Strong energy restoration | 30u → 10u |
| Herb Bitters (30u+) | Same Herb | **Herb Powder** - Very strong healing | 30u → 10u |

### EXPERT Level (Skill 4)

| Base Reagent | + Herb | = Product | Ratio |
|--------------|--------|-----------|-------|
| Vitriol of Herb (30u+) | Same Herb | **Herb Salt** - Most potent but risky healing | 30u → 10u |

## Examples

### Creating Rosa Tonic (NOVICE)
1. Fill cauldron with 30+ units of water
2. Add one rosa herb
3. Light and wait
4. Result: ~10 units of "rosa tonic"

### Creating Multiple Products at Once
1. Fill cauldron with 90 units of water, 60 units of wine, and 30 units of oil
2. Add one mentha herb
3. Light and wait
4. Result: ~30 units of "mentha tonic", ~20 units of "mentha elixir", and ~10 units of "mentha oil"

### Creating Calendula Concentrate (AMATEUR)
1. First, make calendula tonic (water + calendula)
2. Pour the tonic back into the cauldron (need 30+ units)
3. Add another calendula herb
4. Light and wait
5. Result: ~10 units of "calendula concentrate"

### Efficient Batch Processing
1. Fill cauldron with 90 units of water
2. Add one rosa herb
3. Result: ~30 units of "rosa tonic"
4. Pour tonic back into cauldron (now have 30u)
5. Add another rosa herb
6. Result: ~10 units of "rosa concentrate"

## Important Notes

- You must use EXACTLY ONE herb per batch
- The herb name will be part of the final product name
- Different herbs will create products with the same base effects, but named differently
- Skill requirements must be met or the brew will fail and create yuck (proportional to input)
- **NEW:** Multiple base reagents can be processed simultaneously
- Each base reagent requires a minimum of 30 units
- Conversion ratio is 30u input → 10u output (33% efficiency)
- This system works alongside the traditional potion system

## Tips

- Start with novice recipes to build alchemy skill
- Wine creates elixirs, other alcohols create bitters
- Secondary processing (boiling again) requires the same herb type
- Failed brews will teach you experience, but waste ingredients
- Stock up on common herbs like rosa and mentha for practice
- **NEW:** You can create multiple types of products in a single batch by adding multiple base reagents!
- Optimal efficiency: Use exactly 30u of each base reagent you want to process
